# Counter-Case

Pure artifact. No verdict on whether the proposal is wrong — just the strongest argument against.

## Output

1. **The best argument against** — argued from the proposal's own facts, not strawmen.
2. **What it would take to answer it** — the evidence or change that would settle the counter-case.
3. **The weakest defense** — the easiest objection the proposal's defenders would face.

```
## COUNTER-CASE

### The strongest argument against
- <argument, from the proposal's own facts>

### What would answer it
- <evidence or change that settles it>

### The easiest objection to raise
- <the point most likely to stick>
```
