# Assumption Hunt

Pure inventory. No verdict.

## Output

1. **Assumptions** — each unstated belief the proposal depends on.
2. **Kill conditions** — for each, what would show it false.
3. **Load-bearing assumptions** — ones where the whole proposal collapses if wrong.

```
## ASSUMPTIONS

| # | Assumption | Kill condition | Load-bearing? |
|---|---|---|---|

### Collapse points
- <the load-bearing assumption(s) whose failure kills the proposal>
```
