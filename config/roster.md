# Roster

Every bot in the system, one row per bot. A bot finds its own row by its name. This is why no naming convention is imposed: existing bots keep whatever names they already have, and an adopter running a different framework fills in theirs. The roster is also the only place the whole fleet is visible outside the runtime's own UI.

Repo assignment works as default plus override. The roster holds a bot's default project repo, and an individual assignment may name a different one.
