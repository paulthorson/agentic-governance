# Research Synthesis

Pure artifact. Synthesize only what the input contains.

## Output

1. **Themes** — each with the evidence-linked claims that support it (quote the source).
2. **Tensions** — where the input points in different directions.
3. **Gaps** — what the input does not cover, named.
4. **What was NOT asserted** — a note that nothing was added beyond the input.

```
## SYNTHESIS

### Themes
- <theme> — <evidence-linked claim> (<source>)

### Tensions
- <conflict in the input>

### Gaps (not covered by input)
- <gap>

### Integrity
- <statement that nothing was added beyond the input>
```
