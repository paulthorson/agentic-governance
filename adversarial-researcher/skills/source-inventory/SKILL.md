# Source Inventory

Pure inventory. No verdict.

## Output

1. **Sources** — each with type (primary/secondary/promotional), date, and what claim it
   supports.
2. **Single-source claims** — claims resting on one source, flagged for the Critic.
3. **Undated / unattributed** — sources without a date or clear origin, named.
4. **Missing** — claims with no source at all, named (never filled in).

```
## SOURCE INVENTORY

| Claim | Source | Type | Date | What it supports |
|---|---|---|---|---|

### Single-source claims
- <claim | the one source>

### Undated / unattributed
- <source>

### Claims with no source
- <claim> (Rule 1 — routes to the Evidence Advocate)
```
