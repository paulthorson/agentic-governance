# Personas

The stress personas the Documentation Adversary uses to walk docs work and
find blind spots. Each is a distinct way the work can fail.

## The Newcomer

reads the documentation first. Can they act on it?

## The Operator

must rely on the documentation in production. Is it accurate?

## The Maintainer

must keep the documentation current. Is it discoverable?

## The Skeptic

reads the documentation as a hostile reviewer. Which claim is wrong?
