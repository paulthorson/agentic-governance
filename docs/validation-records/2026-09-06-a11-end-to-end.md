# A11 End-to-End Validation Record — false-premise epic

**Epic:** "Add a `--dry-run` flag to the calibration-report script so operators can preview a report without writing it" (deliberately solution-framed).
**Date:** 2026-09-06. **Chain:** CEO → Research → PM (→ escalation to CEO → human).
**Method:** Each role ran as its own **isolated subagent** (no shared reasoning). Each loaded the constitution + its harness + only the single upstream artifact.

## What the chain did

1. **CEO** received the solution-framed objective. Per A18.3, it restated it as a problem ("How can an operator inspect the full contents and destination of a calibration report before any file is written.") and produced a research question with genuine alternatives. **A18.3 verified again in the full chain** (unprompted restatement).

2. **Research** read the actual script (`scripts/calibration-report.py`) and found the **premise is false**: the script has **no write path** — it only reads the verdict ledger and prints to stdout. There is no destination, no write, no partial-write risk. The evidence-supported conclusion is **option F: do nothing**. Research also flagged a harness conflict: the research question asked it to "recommend," which conflicts with the researcher harness's prohibition on recommending a course of action.

3. **PM** received the evidence pack. Per its harness stop conditions, it **escalated to the CEO** rather than fabricate a brief: it cannot tie the work to a business goal (the premise is false) and cannot produce two genuinely different approaches to a non-problem. It explicitly refused to fill required fields with placeholders.

4. **CEO → human.** The escalation is a novel case with no precedent, so it routes to the human (mandatory escalation, Section 10.3). The human decides whether to drop the epic (option F) or reframe it.

## What this proves

**The chain works end to end.** It caught a false-premise epic and escalated rather than producing fabricated work:

- **A18.3 works** — the CEO restated the solution-framed objective as a problem, unprompted.
- **Research is a real check** — it read the actual script and found the premise false, rather than accepting the objective at face value.
- **The PM harness's stop conditions work** — the PM escalated instead of fabricating a brief to satisfy the format. This is the "never fill a required field with a placeholder" rule in action.
- **The chain does not stall** — it reached a clean escalation, not an infinite bounce between roles.

## What broke / findings

- **The epic was a non-problem.** The `--dry-run` flag would solve a problem that does not exist (the script never writes). This is a finding about the epic, not the framework — the framework correctly caught it.
- **Harness conflict surfaced:** the research question asked the researcher to "recommend," which conflicts with the researcher harness's prohibition on recommending. The researcher handled it by documenting alternatives factually without selecting one. This is a minor spec/harness tension worth noting (the research-question template should not ask the researcher to recommend).

## Recommendation

The epic should be **dropped (option F)** — the script has no write path, so there is nothing to preview. If a write capability is added later, the preview question becomes relevant then. The harness-conflict note (research question asking the researcher to recommend) should be fixed in the research-question template.
