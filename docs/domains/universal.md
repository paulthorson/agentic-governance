# Universal Domain — deep dive

**Plugin:** `adversarial-universal/` · **Veto:** irrecoverable harm of any kind

## What it reviews

A single adversary applicable anywhere — PM, BA, Scrum Master, CEO, or any
catch-all role. The domain-agnostic reviewer.

## Adversary agents

| Agent | Role |
|---|---|
| `universal-adversary` | The single reviewer — applies four domain-agnostic checks |

## The four checks

1. **Altitude** — is the work at the right level of abstraction?
2. **Trade-off** — were genuine alternatives weighed, not variations?
3. **Harm / blind spots** — what could go wrong that wasn't considered?
4. **Falsifiability** — is the claim testable, or unfalsifiable?

## Skills

`univ-altitude-check`, `univ-assumption-hunt`, `univ-blind-spot-search`,
`univ-counter-case`, `univ-decision-gate`, `univ-risk-scan`,
`univ-adversarial-universal` (worker).

## Constitution / veto

The universal constitution gates on **irrecoverable harm of any kind** — work
that risks harm that cannot be undone is kicked back. Only a human clears a
veto.

## How to use

```
Use the governance server to run a review of this work in the universal domain:
<your work>
```
