# Initiatives

One folder per shipped initiative, each with an `EVIDENCE.md`: scope, governance
verdicts, metrics, and disclosed caveats.

Build coordinators: as each initiative's Proof of value is met, publish here —
new folder, `EVIDENCE.md` in the same format, then update the evergreen
`analytics/` README in place (move the superseded version to `analytics/archive/`). Commit and push on your branch; open a PR for maintainer merge.
