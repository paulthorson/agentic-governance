## 1. Design fundamentals for elevated dark KG (OPENED sources)

Stacks on #37 fundamentals (Fitts/Hick/Gestalt/Munzner/Tufte) + RESEARCH_HCI #38. This pack adds dark-elevation + contrast craft.

### 1.1 Dark depth, saturation, legibility

| Principle | Opened source | Compose rule for elevated AG KG |
| --- | --- | --- |
| **Dark depth via lightness stack** | https://www.nngroup.com/articles/dark-mode-users-issues/ (opened) | On dark UIs, lighter surfaces read as closer; black-on-black “shadow” reads as glow. Build depth with **layered grays** (deepest black ground → slightly lifted panel → brightest labels), not neon bloom as fake shadow. |
| **Saturated color on dark blurs** | same NN/g dark-mode issues (opened) | Highly saturated accents on dark backgrounds hurt visibility even near WCAG edge. Prefer **desaturated / lifted phosphor** for body labels; reserve max neon for sparse status accents. |
| **Thin / thick type on dark** | same | Thin fonts get swallowed; heavy type bleeds. Prefer medium weights for `Improve` / `Retro` / `PR merged` / `ROLE` labels on dark. |
| **Text over busy fields** | https://www.nngroup.com/articles/text-over-images/ (opened) | Rain/grid behind labels needs darken / overlay / local scrim so text meets contrast — same as text-over-image craft. |

### 1.2 Contrast bars (accessibility)

| Principle | Opened source | Compose rule |
| --- | --- | --- |
| **Text contrast ≥ 4.5:1** (normal) / **3:1** large | https://webaim.org/articles/contrast/ (opened) | Artifact labels and inspect copy must clear AA on actual local background (including over rain). Pure `#00FF00` on black is **not** automatically readable craft — measure. |
| **Non-text contrast ≥ 3:1** for UI + meaningful graphics | https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast.html (opened); WebAIM non-text notes | Nodes, edges, focus rings, hit targets need ≥3:1 vs adjacent dark. Glow alone ≠ contrast. |
| **Color not sole channel** | WebAIM 1.4.1 notes (opened article) | Stamp PASS/CONCERN/BLOCKER and class (Improve/Retro/PR/ROLE) need shape / label / pattern — not hue alone. |

### 1.3 Atmosphere vs data (rain / grid)

| Principle | Opened source | Compose rule |
| --- | --- | --- |
| **Rain as ambience** | https://github.com/nicecx/dsh-matrix-skin (opened README) — near-black green `#040805`, ink-green body `#7dffb3`, brand `#00e676`; rain canvas **10% opacity**, **20fps** cap, `pointer-events:none`, auto-off under `prefers-reduced-motion`, paused when tab hidden | Digital rain is **atmosphere**, not measured ink. Match this order of magnitude (≤10% presence); never steal Fitts hits; honor reduced motion; idle still when honesty requires. |
| **Density with hierarchy** | https://gmunk.com/TRON-Ares-Computer-Vision (opened) — GMUNK TRON:Ares CV: density as consequence of awareness; squarepack lattice; connect then populate; hierarchy of large structures + fine detail | Elevation = **organized density** (scan → track → connect → populate), not random green noise. Grid as spatial map for where info may live. |
| **Tron HUD system craft** | https://thegridcn.com/ (opened) — Tron-inspired shadcn theme: HUD/data-card/radar, glow utilities, 3D grid | Peer for elevated dark chrome + glow utilities. **Competitor-hole:** movie HUD spectacle / continuous Three.js wow can drown readable KG — adapt tokens, not light-cycle wallpaper. |

## 3. Compose elevated readable AG KG (senior-director brief)

**Job:** Same Obsidian-class measured KG (#37) wearing **elevated dark-ops / Matrix-Tron atmosphere** — deep black, phosphor green, depth, rain/grid as mood — while labels (`Improve` / `Retro` / `PR merged` / `ROLE`) and codes stay readable. FAIL cheap wallpaper + blob.

### 3.1 Layer model (bottom → top)

1. **Ground:** near-black void (`#050505`-class) — deepest. 
2. **Atmosphere (optional):** rain/grid at **≤10%** effective presence (dsh-matrix-skin opened: 10% opacity / 20fps); `pointer-events: none`; reduced-motion = off; never crosses label glyphs at full strength. 
3. **Graph field:** slightly lifted panel / vignette so edges+nodes clear (NN/g depth stack). 
4. **Marks:** point nodes + connection edges; size = measured connectivity; class via hue **and** label/shape. 
5. **Labels:** medium-weight phosphor / lifted green-gray meeting **4.5:1** on local bg; scrim behind label if atmosphere conflicts. 
6. **Inspect / toast:** lighter elevated surface; quiet measured copy; toast then persist (#27/#28). 
7. **Idle:** still. Event micro-twitch only on measured write. No continuous rain “alive” as status.

### 3.2 Encoding (Munzner + elevation)

| AG attribute | Mark / channel | Elevated note |
| --- | --- | --- |
| Artifact / code | Point + `P-0n` | Contrast-safe label; never rain-obscured |
| Class | Hue + readable word (`Improve`/`Retro`/`PR merged`/`ROLE`) | Color not sole channel |
| Connectivity | Size | Keep; avoid neon bloom replacing size |
| Focus | Hover neighborhood | Fitts targets large; glow optional accent only |
| Event | Micro-twitch | Not rain speed-up; not Animate time-lapse |
