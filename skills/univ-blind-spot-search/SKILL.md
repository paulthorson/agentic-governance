# Blind-Spot Search

Pure inventory. No verdict.

## Output

1. **Perspectives not argued** — run each: end user / affected party, operator, skeptic, future.
2. **For each**: what that party would say, and what the proposal does not address.
3. **The most neglected** — the perspective with the highest stakes that nobody argued.

|---|---|---|
