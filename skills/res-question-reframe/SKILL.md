# Question Reframe

Pure artifact. No verdict.

## Output

1. **The reframed question** — at the altitude that can be answered.
2. **Answer conditions** — what would have to be observed to answer it, and what would falsify it.
3. **Answer shapes** — what a good answer looks like (a number, a range, a set of cases, a
   decision), and what would be an inadequate answer.

```
## REFRAMED QUESTION

### Question
- <reframed>

### Conditions for an answer
- <what must be true / what would falsify>

### Adequate vs inadequate answer
- Adequate: <shape>
- Inadequate: <shape>
```
