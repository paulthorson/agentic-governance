# Decision Gate

Pure artifact. No verdict.

## Output

1. **The decision needed** — what a human arbiter must actually decide.
2. **The options** — each with what it trades away (Rule 2).
3. **What would change the answer** — the evidence, condition, or override that would flip it.
4. **The named arbiter** — who must clear any veto, and why.

```
## DECISION GATE

### The decision needed
- <what the human must decide>

### Options
| Option | Trades away | To get |
|---|---|---|

### What would change the answer
- <evidence or condition>

### Arbiter
- <who must clear a veto, and the reason required>
```
